# Task-001: Scaffold, Design System e Base Mobile-Only

## Resumo da Implementação

Esta tarefa cria a base completa do projeto Pulsar, incluindo:
- Scaffold React + TypeScript + Vite
- Configuração Firebase
- Sistema de design baseado nos tokens do design oficial
- Estrutura de testes
- Documentação de decisões técnicas

## Decisões Técnicas

### Stack Tecnológica
- **React 19**: Framework principal, compatível com React Server Components futuras
- **TypeScript 5.8+**: Tipagem estrita
- **Vite 6**: Build tool e dev server
- **Firebase 11**: Auth, Firestore, Hosting
- **Yarn**: Gerenciador de pacotes
- **Vitest**: Testes unitários
- **Playwright**: Testes E2E
- **Tailwind CSS**: Sistema de design (via configuração customizada)

### Estrutura de Diretórios

